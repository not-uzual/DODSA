# Build an array with stack operation

### Problem
> [Leetcode Problem](https://leetcode.com/problems/build-an-array-with-stack-operations/description/?envType=problem-list-v2&envId=dsa-linear-shoal-stack)

### Thought Process
> In the question it was given that target is increasing array but not necessarily arithmetic progression. So whatever is being pushed must be popped if stream element is smaller than my current element in the target.

```java
class Solution {
    public List<String> buildArray(int[] target, int n) {
        
        ArrayList<String> list = new ArrayList<>();

        int i = 0;
        int curr = 1;
        while(i<target.length) {
            if(curr == target[i]) {
                list.add("Push");
                i++;
                curr++;
            }
            else{
                int jump = target[i] - curr;

                for(int j = 0; j<jump; j++){
                    list.add("Push");
                    list.add("Pop");
                }
                list.add("Push");
                curr = target[i]+1;
                i++;
            }
        }
        return list;
    }
}

```
