# Final Prices With a Special Discount in a Shop

### Problem

>[Leetcode Problem](https://leetcode.com/problems/final-prices-with-a-special-discount-in-a-shop/description/?envType=problem-list-v2&envId=dsa-linear-shoal-monotonic-stack)

### Thought Process

> Maintain a stack of minimum element to the right of current element and if there is minimum element subtract it from current element else current element is the answer.

```java
class Solution {
    public int[] finalPrices(int[] prices) {
        int n = prices.length;
        Stack<Integer> minStk = new Stack<>();

        int[] ans = new int[n];

        for(int i=n-1; i>=0; i--) {
            while(!minStk.isEmpty() && minStk.peek() > prices[i]) minStk.pop();
            if(minStk.isEmpty()) {
                ans[i] = prices[i];
            }else{
                ans[i] = prices[i]-minStk.peek();
            }
            minStk.push(prices[i]);
        } 
        return ans;
    }
}
```

### Thought Process

> For the current element I compared if next element is smaller then current assign that(because j>i is p0) else if next element nearest smallest is smaller then current assign that(p1) else assign -1(no nearest smallest). But it will go wrong for 1, 7, 6, 1 because for 0th index nearest smallest is 1 but it will give -1 according to my approach. My sight was limited to next element and next element smallest element.

```java
class Solution {
    public int[] finalPrices(int[] prices) {
        int n = prices.length;
        int[] minPriceToTheRight = new int[n];
        int[] ans = new int[n];

        minPriceToTheRight[n-1] = -1;

        int minPIndx = n-1;
        for(int i=n-2; i>=0; i--) {
            if(prices[i+1]<=prices[i]) {
                minPriceToTheRight[i] = prices[i+1];
            }else if(minPriceToTheRight[i+1]<=prices[i]) { 
                minPriceToTheRight[i] = minPriceToTheRight[i+1];
            }else {
                minPriceToTheRight[i] = -1;
            }
        }

        for(int i=0; i<n; i++) {
            ans[i] = 
            minPriceToTheRight[i] != -1 && prices[i] - minPriceToTheRight[i] >= 0 ? 
            prices[i] - minPriceToTheRight[i] : prices[i];
        }
        return ans;
    }
}
```
