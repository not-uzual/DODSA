# Exclusive Time of Functions

### Problem
> [Leetcode Problem](https://leetcode.com/problems/exclusive-time-of-functions/?envType=problem-list-v2&envId=dsa-linear-shoal-stack)

### Thought Process
> Use a stack to track the currently running function. Whenever a function starts, the previous top function gets currentTime - prevTime, then push the new function and set prevTime = time. Whenever a function ends, the top function gets currentTime - prevTime + 1, then pop it. After an end, set prevTime = currentTime + 1 because that timestamp is already counted.

```java
class Solution {
    public int[] exclusiveTime(int n, List<String> logs) {
        
        int[] result = new int[n];
        Stack<Integer> stack = new Stack<>();
        int prevTime = 0;

        for (String log : logs) {
            String[] parts = log.split(":");

            int id = Integer.parseInt(parts[0]);
            String type = parts[1];
            int time = Integer.parseInt(parts[2]);

            if (type.equals("start")) {
                if (!stack.isEmpty()) {
                    result[stack.peek()] += time - prevTime;
                }
                stack.push(id);
                prevTime = time;
            } else {
                result[stack.pop()] += time - prevTime + 1;
                prevTime = time + 1;
            }
        }

        return result;
    }
}
```
